# mikan-addon-nodestatus

Community-аддон для панели mikan (protocol 2): мониторинг нод.

- Проверяет ноды по TCP каждую минуту, меряет задержку
- Хранит историю в KV панели, считает аптайм за 24ч / 7д / 30д
- Админ-дашборд на вкладке аддона в панели
- Публичная страница статуса → пушится на GitHub Pages
- Email-алерты при падении/поднятии ноды (опционально)

## Настройка после установки

1. Откройте вкладку аддона в панели mikan (Аддоны → Статус нод).
2. В «Настройках» добавьте ноды: название, код, хост, порты.
3. Для публичной страницы:
   - создайте **публичный** репозиторий для страницы (например `vpn-status`),
   - включите GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root,
   - в настройках аддона укажите владельца, репозиторий и токен (`public_repo` scope достаточно).

## Релиз

Пуш тега `vX.Y.Z` → Actions собирает multi-arch образ в `ghcr.io/<owner>/tool-nodestatus`,
генерирует и подписывает `mikan-addon.json` (+ `.sig`) и прикладывает их к GitHub-релизу.
Индексатор mikan подхватывает релиз по топику `mikan-addon` в течение часа.

Нужные secrets репозитория:

- `MIKAN_ADDON_SIGNING_KEY` — base64 Ed25519 seed (32 байта), подпись релизов
- `MIKAN_ADDON_PUBKEY` — base64 Ed25519 public key, поле `key` в манифесте
