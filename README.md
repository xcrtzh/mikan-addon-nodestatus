# mikan-addon-nodestatus

Community-аддон для панели mikan (protocol 2): мониторинг нод.

- Проверяет ноды по TCP каждую минуту, меряет задержку
- Хранит историю в KV панели, считает аптайм за 24ч / 7д / 30д
- Админ-дашборд на вкладке аддона в панели
- Публичная страница статуса: аддон отдаёт её сам (порт 8080), мобильная вёрстка
- Email-алерты при падении/поднятии ноды (опционально)

## Настройка после установки

1. Откройте вкладку аддона в панели mikan (Аддоны → Статус нод).
2. В «Настройках» добавьте ноды: название, код, хост, порты.

## Публичная страница статуса

Аддон сам отдаёт страницу статуса на порту **8080** (без авторизации, только
публичные данные — админка и API там недоступны). Варианты доступа:

- **Напрямую**: `http://IP-сервера:8080/` — работает сразу, ничего настраивать не нужно.
- **Через reverse proxy** (красивый URL без порта): проксируйте домен на
  `http://127.0.0.1:8080/`. Пример для nginx:

  ```nginx
  server {
      listen 80;
      server_name status.example.com;
      location / {
          proxy_pass http://127.0.0.1:8080/;
          proxy_set_header Host $host;
      }
  }
  ```

  Порт 8080 аддона фиксирован; порт панели (`MIKAN_ADAPTER_LISTEN`) назначает
  панель и он может меняться — для прокси используйте именно 8080.

- **GitHub Pages** (опционально, по-старому): в настройках аддона укажите
  владельца, репозиторий и токен — страница будет пушиться туда как раньше.
  Для этого создайте публичный репозиторий, включите Pages
  (Settings → Pages → Deploy from a branch → `main` / root).

## Релиз

Пуш тега `vX.Y.Z` → Actions собирает multi-arch образ в `ghcr.io/<owner>/tool-nodestatus`,
генерирует и подписывает `mikan-addon.json` (+ `.sig`) и прикладывает их к GitHub-релизу.
Индексатор mikan подхватывает релиз по топику `mikan-addon` в течение часа.

Нужные secrets репозитория:

- `MIKAN_ADDON_SIGNING_KEY` — base64 Ed25519 seed (32 байта), подпись релизов
- `MIKAN_ADDON_PUBKEY` — base64 Ed25519 public key, поле `key` в манифесте
